# Python Expense Tracker 💰

A command-line application for recording and tracking personal expenses using Python.

## Features
- Add expenses with names, amounts, and categories
- View all recorded expenses
- Calculate total expenses
- Calculate spending by category
- Validate user input

## Requirements
- Python 3

## How to Run
```bash
python main.py
```

## Concepts Learned
- Functions
- Lists and dictionaries
- Loops and conditional statements
- Exception handling
- The `sum()` function
- Data aggregation

## Note
This beginner version stores expenses in memory.
Expenses are cleared when the program exits.
